# Internship Application Portal

## Overview
This project was processed using the SDLC Factory.

## Functional Requirements
- The system allows students to register and login
- Students can search and apply for internships
- HOD can approve internship applications

## Non-Functional Requirements
- The system must be secure and reliable

## System Architecture
Architecture: Layered Architecture

- **User Interface**: Accept user input and display results.
- **Application Layer**: Coordinate application workflows.
- **Business Logic Layer**: Execute core application operations.
- **Data Layer**: Store and retrieve application data.
